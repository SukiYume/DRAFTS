可以实现，而且可以做到**对现有工程很少改动**：只多一个“预测模型 + 序列数据集”，训练脚本几乎复用现在这套。

下面我按“怎么接到你现在项目上”一步一步说，所有东西都围绕三个新东西：

1. 一个**序列版 Dataset**：从 H5 里拿“前几帧 → 预测当前帧”
2. 一个**Temporal Predictor 模型**：输入多帧，预测最后一帧
3. 一个**训练/推理入口**：基本复用你现在的 train_ddp / run_inference 逻辑

## 1. 序列 Dataset：从 H5 里拿 (前 T–1 帧, 当前帧)

你现在的 `H5RadioDataset` 是一张一张图拿（`images[i]`），想做“next-frame 预测”就要变成：

> 对同一个 `(name, down_time)` 下，按 `slice_idx` 排序，用前 `T-1` 帧预测第 `T` 帧。

核心思路（伪代码级）：

```python
# dataset_h5.py 里新增一个 Dataset 类
class H5SequenceDataset(Dataset):
    """
    用于 next-frame 预测：
      输入: X_seq: [T-1, 1, 512, 512]
      目标: y:     [1, 512, 512]
    """

    def __init__(self, h5_path, down_times=None, seq_len=3,
                 transform: Optional[Callable]=None):
        self.h5_path = h5_path
        self.seq_len = seq_len
        self.transform = transform

        with h5py.File(h5_path, "r") as f:
            self.images = f["images"]     # (N, 512, 512)
            names = f["names"][:]         # (N, 1)
            down_time = f["down_time"][:] # (N, 1)
            slice_idx = f["slice_idx"][:] # (N, 1)

        names = names.squeeze().astype(str)
        down_time = down_time.squeeze().astype(int)
        slice_idx = slice_idx.squeeze().astype(int)

        # 可选：按 down_times 过滤
        if down_times is not None:
            mask = np.isin(down_time, np.array(down_times, dtype=int))
            names = names[mask]
            down_time = down_time[mask]
            slice_idx = slice_idx[mask]
            self.valid_idx = np.nonzero(mask)[0]
        else:
            self.valid_idx = np.arange(len(names))

        # 按 (name, down_time, slice_idx) 排序
        order = np.lexsort((slice_idx, down_time, names))
        names = names[order]
        down_time = down_time[order]
        slice_idx = slice_idx[order]
        self.sorted_idx = self.valid_idx[order]

        # 构造序列索引列表：[(context_indices, target_index), ...]
        self.samples = []
        start = 0
        N = len(names)
        while start < N:
            # 找同一 (name, down_time) 的连续段
            name0 = names[start]
            dt0 = down_time[start]
            end = start + 1
            while end < N and names[end] == name0 and down_time[end] == dt0:
                end += 1

            # 这一段 [start, end) 是一个时间序列
            length = end - start
            if length >= seq_len:
                for t in range(seq_len-1, length):
                    ctx = self.sorted_idx[start + t - (seq_len-1): start + t]  # T-1 帧
                    tgt = self.sorted_idx[start + t]                           # 当前帧
                    self.samples.append((ctx, tgt))
            start = end

    def __len__(self):
        return len(self.samples)

    def __getitem__(self, i):
        ctx_idx, tgt_idx = self.samples[i]
        with h5py.File(self.h5_path, "r") as f:
            imgs = f["images"][ctx_idx]     # (T-1, 512, 512)
            tgt = f["images"][tgt_idx]      # (512, 512)

        # data augmentation 对每帧做同样的增强（可选）
        if self.transform is not None:
            imgs = np.stack([self.transform(im) for im in imgs], axis=0)  # (T-1, 512, 512)
            tgt = self.transform(tgt)

        # 增加 channel 维
        imgs = torch.from_numpy(imgs).unsqueeze(1)  # (T-1, 1, 512, 512)
        tgt = torch.from_numpy(tgt).unsqueeze(0)    # (1, 512, 512)

        return imgs.float(), tgt.float()
```

> 这样你在训练“预测模型 C”时，一个样本就是 `(context_frames, target_frame)`，两边都 still 是 512×512 图，只是输入多了一个时间维。

## 2. Temporal Predictor 模型：用现有 encoder/decoder，聚合多帧

最省事的办法：**不用造新骨干**，直接复用你现在 `ConvNeXtEncoder + Decoder` 或“简化 encoder + Decoder”。

### 模型结构

* 输入：`x`，shape `[B, T-1, 1, 512, 512]`
* 做法：

  1. 把时间维展开成 batch：`x_flat = x.view(B*(T-1), 1, 512, 512)`
  2. 送进 encoder，得到多尺度特征 `[f0, f1, f2, f3]`
  3. 把这些特征 reshape 回 `[B, T-1, C, H, W]`，对 T 维做平均（或加权）→ 得到“过去几帧的平均表示”
  4. 只用这个聚合后的特征进入 decoder，输出一帧预测图：`y_pred [B, 1, 512, 512]`

在 `models.py` 里加一个类，比如：

```python
class TemporalPredictor(nn.Module):
    """
    Next-frame predictor:
      输入: x [B, T-1, 1, 512, 512]
      输出: y_pred [B, 1, 512, 512]
    """

    def __init__(self, in_channels=1, pretrained=False, seq_len=3):
        super().__init__()
        self.seq_len = seq_len
        self.encoder = ConvNeXtEncoder(in_channels, pretrained)  # 或你的小 encoder
        self.decoder = Decoder(out_channels=in_channels)

    def forward(self, x):
        B, Tm1, C, H, W = x.shape    # Tm1 = T-1
        assert Tm1 == self.seq_len - 1

        # 展开时间维
        x_flat = x.view(B * Tm1, C, H, W)

        # 编码所有过去帧
        f0, f1, f2, f3 = self.encoder(x_flat)  # 每个都是 [B*Tm1, Ck, Hk, Wk]

        # reshape 回 [B, Tm1, Ck, Hk, Wk]，对时间维做平均
        def agg_feat(f, Ck):
            _, _, Hk, Wk = f.shape
            f = f.view(B, Tm1, Ck, Hk, Wk)
            return f.mean(dim=1)  # [B, Ck, Hk, Wk]

        f0 = agg_feat(f0, 96)
        f1 = agg_feat(f1, 192)
        f2 = agg_feat(f2, 384)
        f3 = agg_feat(f3, 768)

        # 解码成一帧预测图
        y_pred = self.decoder([f0, f1, f2, f3])
        return y_pred
```

> 如果你后面用的是 MobileNet/ShuffleNet 等小 encoder，只要 encoder 也返回 `[f0,f1,f2,f3]` 四个尺度，这个类不用改。

### Loss

可以直接复用你当前的 SmoothL1：

```python
def compute_pred_loss(pred, target, reduction="mean"):
    if reduction == "none":
        err = F.smooth_l1_loss(pred, target, reduction="none").mean(dim=[1,2,3])
        return err, err
    else:
        loss = F.smooth_l1_loss(pred, target)
        return loss, loss
```

### 3.2 推理：滑动序列 + 预测误差当 score

推理时的逻辑：

1. 从 H5 拿某个 `(name, down_time)` 下的所有 slice，按 `slice_idx` 排序；
2. 对每个 t ≥ T-1：

   * 用 `t-(T-1)...t-1` 这些帧作为输入，预测第 t 帧；
   * 计算预测图与真实图之间的误差图（SmoothL1）；
   * 对误差图做 `mean` / `p99` 得到一个 score；

可以写一个简单函数，比如在 `run_inference_predictor.py` 里：

```python
@torch.no_grad()
def compute_pred_scores_for_series(model, series_imgs, seq_len=3, device="cuda"):
    """
    series_imgs: numpy [N, 1, 512, 512]
    返回: scores: [N]，前 seq_len-1 个可设为 nan
    """
    N = series_imgs.shape[0]
    scores = np.full(N, np.nan, dtype=np.float32)

    for t in range(seq_len-1, N):
        ctx = series_imgs[t-seq_len+1:t]     # (T-1, 1, H, W)
        tgt = series_imgs[t]                 # (1, H, W)

        ctx_t = torch.from_numpy(ctx).unsqueeze(0).to(device)  # [1, T-1, 1, H, W]
        tgt_t = torch.from_numpy(tgt).unsqueeze(0).to(device)  # [1, 1, H, W]

        pred = model(ctx_t)
        err = F.smooth_l1_loss(pred, tgt_t, reduction="none")  # [1,1,H,W]
        err_flat = err.flatten(1)
        score_mean = err_flat.mean(dim=1)
        score_p99  = torch.quantile(err_flat, 0.99, dim=1)
        score = torch.maximum(score_mean, score_p99)
        scores[t] = score.item()

    return scores
```

> 你就可以把这个 score 当作第二视角的异常分数，再和 AE/VAE 的 score 做 `max` / 排序融合。

## 4. 怎么跟你现有 “AE 异常分数” 结合？

最简单融合策略：

1. AE/VAE：对每个切片算 `score_ae`（重构误差 p99）
2. Predictor：对同一序列上的每个切片算 `score_pred`
3. 最终分数：

   ```python
   score_final = np.nanmax(np.vstack([score_ae, score_pred]), axis=0)
   ```

   （前 `seq_len-1` 帧没有预测分数，用 `score_ae` 即可）

这样：

* background：两种 score 都会较低；
* 瞬时异常 / 突然出现的斜线 / 突然出现的窄带 RFI：

  * AE 效果不一定好，但 Predictor 一般会“预测不出来” → `score_pred` 很大；
* 你最后排序按 `score_final`，就可以自然地把“空间上奇怪 + 时间上不连续”的东西推到前面。

## 小结

你现在这套“图像 AE/VAE”的方案已经很好，加一个 **Temporal Predictor** 其实只需要：

* 多一个 `H5SequenceDataset`（把单帧改成序列）；
* 多一个 `TemporalPredictor`（复用你现有 encoder/decoder，时间维上做平均）；
* 在训练脚本里加一个 `--model pred` 分支；
* 推理时滑动窗口做预测，误差图 + p99 当 score；

这样就实现了我说的那个 **“第二视角：时间一致性异常检测”**，对你那种“突然出现的斜线/FRB/窄带”的敏感度会明显提高，而且不用改掉你现有的 AE/VAE 体系。
